# GENESIS · 一念万物

**双击根目录的 `GENESIS.html`，点击「全屏播放」。**

30 秒、128 BPM、64 拍。黑洞诞生 → 金属结构与解体 → 超光速隧道 → 粒子聚字。

- 网页实时绘制，不是视频文件；没有使用生成图片或视频素材。
- 原创程序合成配乐、云希中文旁白、字体均已内嵌，播放不需要联网或启动服务。
- 全屏后鼠标静止一秒，控件和光标自动隐藏；移动鼠标可重新显示。
- 空格暂停，左右箭头跳转，`R` 重播，`M` 静音，`F` 全屏。
- 含快速运动和短暂强光；可在页脚启用「柔光」。

## 源码与开发

源码位于 `web/`。在该目录执行 `npm install` 后，`npm run dev` 启动开发页面；`npm run build` 重新生成根目录独立 HTML。

`npm test` 检查时间轴；`npm run test:web` 在可见 Chrome 中断网打开独立 HTML，验证完整播放、全屏、拖动与两条渲染路径；`npm run test:audio` 核验母带。

常规硬件使用 Three.js / GLSL。检测到软件 GPU 时才使用 Canvas 向量绘制路径；场景统一由音频绝对时间驱动，低帧率不会累计时序偏差。测试机是虚拟显示环境，不能据其帧率推断实体机器性能。

音频制作脚本 `web/scripts/score.mjs` 可重现母带；重新制作旁白需要 Python 的 `edge-tts` 与 `imageio-ffmpeg`。观看已有 HTML 不需要这些工具。

验证结果与关键帧在 `output/web-qa/`。
