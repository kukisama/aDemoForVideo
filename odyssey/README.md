# 奥德赛 · 无人之名

**180 秒 / 8-bit 像素史诗 / 字幕与原创音乐 / 15 幕、54 个镜头。**

## 直接观看

打开 [`../export/奥德赛/开始观看.html`](../export/奥德赛/开始观看.html)，点击「开始故事」或「全屏启航」。无需联网、开发服务器或安装依赖。移机时复制整个 `export/奥德赛/`，保留 `audio/master.mp3`。

推荐完整 Chrome / Edge。VS Code 的内置预览浏览器在本次测试中无法解码此 MP3，不能用它代替实际浏览器验收。封面「观看设置」可在开播前开启柔和动效。

空格暂停／继续，左右键跳转一小节，`R` 重播，`F` 全屏，`M` 静音。播放中鼠标静止后控件隐藏；可直接全屏录屏，不额外制作 MP4 或 ZIP。

## 这一次的故事与表现

从一个站在家门前的陌生人开始。远征、脱险、失去与归来围绕“名字”展开，最后的识认不靠战绩，而靠共同生活。标题与封面不提前透露识认细节；完整线索收在播放器可折叠说明里。

- 宏观与近景交替：城墙与盾阵、桨船舰队、巨人洞窟、海妖岩柱、六首海兽与漩涡、浪墙、海下残骸、宫殿和故乡海岸。
- 角色具有行走、奔跑、格挡、挥剑、突刺、拉弓、翻滚、攀爬、划桨、伸手、拥抱等关节动作。多人抬桩、拉索与抓木使用手部接触点。
- 战斗有预备、接触和反馈。短剑弧沿实际剑尖生成，盾击圈与局部火花跟随同一音画标记；不使用频繁全屏闪白或血腥伤口。
- 字幕固定在 HTML 阅读层，不随画面冲击；柔和动效减少抖动、天气与局部特效，不改变剧情或音乐时序。

这是以[2026年电影官方公开题材](https://www.odysseymovie.com/synopsis/)与[荷马原著](https://www.gutenberg.org/ebooks/1727)为依据的**非官方原创压缩改编**，不是电影正片复刻或完整剧情解说，不声称再现电影的具体结局。人物、对白、镜头和音乐均为本片原创设计。详细依据和改编边界见 [`facts.md`](facts.md)。

## 音乐

144 BPM，432 拍，108 小节，两个原创主题：八小节远征动机、四小节归家动机。15 段有不同编曲，包括芯片脉冲波、三角低音、数字里拉琴感拨弦、铜管与弦乐感合成、战鼓、FM 铃和复调。30 个原创动作音效与画面共用绝对时间。

音乐与音效全部数学合成，没有旁白、电影原声录音、旋律转写、演员声音或外部采样。8-bit 是音色与美术语言，不是把母带降为 8-bit 音质。

[`audio/report.json`](audio/report.json)记录实际信号测量：180 秒、48kHz 立体声、−12.35 LUFS、−1.95 dBTP、幕间 RMS 差 18.51dB、无削波。122.5 秒缺掉一拍，之后恢复独奏；这些指标不能代替主观试听或审美评价。

| `build.mjs` | 内嵌脚本、样式及拉丁字体，复制已核验MP3，保护其他影片的交付物 |
| `test.mjs` | 实际交付入口的逐镜、字幕、交互、离线复制与完整实播检查 |
| `visual-test.mjs`、`audio-test.mjs` | 独立画面契约与完整音频信号回归 |
| `ODYSSEY.html` | 项目内预览，依赖本目录 `audio/master.mp3`；对外交付用 `export/奥德赛/` |
| `output/qa/` | 浏览器报告、54镜头截图、三张镜头拼图；不进入交付目录 |

开发依赖共用 `../web/node_modules/`；FFmpeg 通过本机 Python 的 `imageio_ffmpeg` 查找。观看成片不需要这些依赖，也不需要环境变量或密钥。

在仓库根目录执行：

1. `node odyssey/score.mjs`：仅当台本或生成器改变时重制音轨，成功验证后才发布。
2. `node odyssey/audio-test.mjs`：16 项回归，包含整段 MP3/WAV 解码、响度、真峰值、声场、静音和素材哈希。
3. `node odyssey/build.mjs`：生成预览与 `export/奥德赛/`，不修改其他影片。
4. `node odyssey/visual-test.mjs --summary`：独立逐镜与角色测试；加 `--edge` 测 Edge。
5. `node odyssey/test.mjs --full`：可见 Chrome、断网 `file://`、原生全屏完整 180 秒，包含片尾重播。
6. `node odyssey/test.mjs --edge`：Edge离线交互与逐镜兼容检查；这条命令不等于完整三分钟实播，需另加 `--full` 才包含实播。
7. `node odyssey/score.mjs --verify`：只读复验已发布音轨与测量报告。

### 已处理的媒体边界

- 144BPM 的分数秒切点会被 Chromium 原生媒体时钟截到整数微秒。只对 <1 微秒的节拍网格误差校正，不移动拍点或放宽毫秒级字幕边界。
- 从片尾快速倒退时，旧的 `ended` 事件可能在新 `seek` 后才到达。处理事件前重新检查 `audio.ended` 和实际位置，避免被旧事件拉回结尾。

测试报告区分实际全片播放与逐镜渲染；本机帧率只代表本机，不用于限制用户正常播放机器。测试通过也不等于故事、画面或音乐已获得用户认可。
