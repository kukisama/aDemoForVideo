# 西部2 · 明天以西

**观看：[export/西部2/开始观看.html](../export/西部2/开始观看.html)**。将整个 `export/西部2/` 目录复制到另一台机器，用 Chrome / Edge 打开，点击“全屏观看”。保留 `audio/`，不需要联网或安装开发依赖。

这是独立新版，不是对 `rdr2/` 的覆盖更新。旧项目和 `export/西部余烬/` 在开工时已做完整哈希记录，构建、验收前后都检查不变。

## 创作变化

- **180 秒，7 段、24 镜头、21 段字幕。**字幕合计 84.9 秒，留出人物反应、动作和环境观察时间。
- **三次 plan。**信任、迟疑、自己作决定，通过递图、推车、回头帮助同行者、折图等原创小事件推进。不是复现游戏任务、原台词或结局，事实范围见 [facts.md](facts.md)。
- **原创口哨与芯片音乐。**80 BPM；近正弦口哨有气声、微小音高漂移与自然收口，配稀疏数字拨弦、三角低音及合成风／纸／木轮／水声。部分段落仅有环境和尾音，不是播放失败；没有借用游戏旋律或原声。
- **原创 HD-2D 方向。**像素人物置于实际三维环境中，采用光照、透明裁切阴影、体积雾带、河面微波、景深和有限辉光。没有使用《八方旅人》或《荒野大镖客》的美术素材。
- **独立近景美术。**全身每帧 96×128，头肩近景每帧 192×224，马匹每帧 160×144；不是把原版小人放大。人物动作按绝对时间选择帧，单次动作停在末帧；地图跟随实际图集手部锚点。

## 播放与画质

使用 WebGL2，内部最高 1280×720，固定 16:9。建议开启浏览器硬件加速并横屏全屏观看。**不会因检测到软件图形设备而自动退回旧二维画面。**本机或虚拟机帧率不等于目标真机表现；工程验收与视觉感染力、音乐气质也分别判断。

空格暂停／继续，左右键跳转三秒，R 重播，F 全屏，M 静音。鼠标移动唤出控制栏；“说明”可设置柔和动效。

## 开发命令

共用仓库 `web/node_modules/` 已有的 Three.js、Vite、字体与 Playwright；**观看者不需要这些依赖**。以下命令在仓库根目录执行：

- 构建：`node rdr2-v2/build.mjs`
- 原片完整性：`node rdr2-v2/protect-original.mjs --verify`
- 关键镜头快检：`node rdr2-v2/test.mjs --quick`
- 全部镜头、边界、动作、控件与便携验证：`node rdr2-v2/test.mjs`
- 加入正常速度三分钟实播：`node rdr2-v2/test.mjs --full`
- Edge 关键镜头兼容检查：`node rdr2-v2/test.mjs --edge --quick`
- 音频独立复验：`node rdr2-v2/score.mjs --verify`
- 音频回归：`node --test rdr2-v2/audio-test.mjs`

浏览器验收默认不占桌面，可加 `--headed` 显示自有测试窗口，不连接或接管用户已有浏览器。报告记录最终HTML／MP3哈希、实际音频时钟和帧数；完整播放不使用加速时钟。测试结果仅覆盖声明的工程范围，不冒充人工试听或用户审美认可。
