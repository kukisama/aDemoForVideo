# 《门外》史实与文学创作边界

这不是秦始皇的自传、真实录音或名言合集。全部第一人称台词均为本片原创文学独白，结尾为想象中的身后回望，不代表历史人物确曾作过相同反省。

## 进入成片的历史骨架

| 片中内容 | 核对依据与限制 |
|---|---|
| 少年居高位，秦之外有六国 | [大都会艺术博物馆亚洲艺术部的秦代文章](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)明确写到兼并其余六个战国国家；其即位年龄表述与[World History Encyclopedia 生平](https://www.worldhistory.org/Shi_Huangdi/)不同，片中只写“少年”，不选取有分歧的具体年龄。 |
| 统一六国、称始皇帝 | [World History Encyclopedia 生平年表](https://www.worldhistory.org/Shi_Huangdi/)记载统一完成于公元前221年。台词“他们叫我”是称号的文学表达，不是群臣对话实录；六道门是意象，不是六次具体战役复原。 |
| 文字、度量衡、货币及道路 | [大都会艺术博物馆正文第二段](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)明确提及文字、货币、计量体系标准化与道路、运河网络扩展。影片不宣称秦始皇创造了文字、首次发明道路或消除全部地方差异；“一斤”不等于今日500克。 |
| 北方边墙与徭役代价 | [大都会艺术博物馆](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)提及连接北方既有防御墙；[World History Encyclopedia 的长城文章](https://www.worldhistory.org/Great_Wall_of_China/)区分秦代墙体与今日主要为明代修建的长城，并讨论征役。画面采用夯土层纹、木夯与黄土山脊，不画明代砖垛和密集敌楼。劳作者为原创合成人物，不赋予具体身份和未经证实的死亡数字。 |
| 思想控制 | [大都会艺术博物馆](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)记述公元前213年的禁毁典籍。片中以诏书、灯熄、低头静默的朝堂表现，不声称所有书籍都被焚毁，不描画处刑，也不以贡献抵消代价。 |
| 求仙与海上远行 | [World History Encyclopedia 生平](https://www.worldhistory.org/Shi_Huangdi/)记述求长生的活动。台词把“不死之药”作为人物听闻的说法，并未确认它存在；船只没入雾中是文学镜头，不构造真实仙山或编造使者归来结局。 |
| 陵墓与兵马俑 | [World History Encyclopedia 陶俑文章](https://www.worldhistory.org/Terracotta_Army/)明确说明大型陵墓工程在即位早期已经开始，故台词是“早已在成形”，不是求仙失败后才动工。[大都会艺术博物馆](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)说明主墓室尚未发掘；影片不把地下水银河、自动机关等画成实地所见。 |
| 巡行中去世与秦朝短促 | [World History Encyclopedia 生平](https://www.worldhistory.org/Shi_Huangdi/)记载其于公元前210年巡行期间去世，并列出秦朝公元前221—206年的年表。关于死因，不采用该站部分文章将水银中毒确定化的表述；“是时间”是有限生命的文学命题，不是医学诊断或排除其他死因的史学结论。 |

## 视点、形象与结尾

- 前150秒主要以皇帝的眼睛、手和车窗组织镜头；军阵、劳役、工坊采用主观观察与记忆蒙太奇，不声称秦始皇亲自指挥了每个动作。工匠双手属于被观察者，不把皇帝写成陶俑雕刻者。
- 150秒后持续标注“身后回望 · 文学想象”。宫阙风化、陌生人读懂彼此、普通人走出大门，均是本片的创作表达，不是秦始皇预知未来。
- 开场门闩、竹简递出、结尾开门是重复发展的视觉意象。最后的“天下，不必永远属于我”不是古籍引文，也不代表历史人物实际改变过立场。
- 黑袖、交领、低平屋顶、编连竹简、圆形方孔钱与陶俑甲片采用概括性像素设计；不以“考据复原”宣传具体配色、服制、器物形制或建筑尺寸。
- 简册与旗上的符号为装饰性点阵笔画，**不声称是可释读的秦文字**。人物没有现代制服、清代发式或黄色龙袍。
- 兵马俑的数量表现为多排的视觉规模，不配未经核定的实际总数；图形也不是某件具体出土文物的复制品。

## 获取与来源透明性

制作时已实际读取上表 World History Encyclopedia 四篇正文。该站是历史教育类二手资料，并非中国文物机构，存在需排除的争议与概括，未全盘照搬。

[大都会艺术博物馆正文](https://www.metmuseum.org/essays/qin-dynasty-221-206-b-c)最初在摘要读取时被错误引向广告端点；随后通过正常浏览器打开官方网站，读取到亚洲艺术部的完整三段正文并逐项核对。本片未读取广告端点作为史料，也未把它列入链接。

UNESCO、Britannica 和部分其他站点未能取得正文，故不把失败的请求包装成独立核验。未使用这些网页图片或复制正文用于动画。
