# 门外 · 秦始皇

180秒第一人称文学动画，30镜头、14段、26段中文男声独白。纯二维8-bit画面，原创120BPM芯片配乐。通过关门、开疆、标准化、徭役、求长生与身后回望，回收开场的脚步悬念。

## 播放

最终入口：[`../export/秦始皇/开始观看.html`](../export/秦始皇/开始观看.html)。用Chrome或Edge双击打开，点击“全屏入场”。**复制整个 `export/秦始皇/` 文件夹，保留同级 `audio/`**，断网可用。没有MP4或ZIP，也不需要开发服务器。

音轨不再以Base64写入HTML正文；HTML保留可直接读取的页面、动画代码、时间轴和字体，音频使用普通相对路径：

- `audio/master.mp3`：旁白与配乐混音。
- `audio/music.mp3`：纯配乐。

项目内预览`QIN.html`同样引用本项目的`audio/`，不是独立单文件。

默认男声独白＋配乐；`V`切换为纯配乐，字幕继续讲述故事。空格暂停、左右键前后5秒、`R`重播、`M`静音、`F`全屏。说明面板可隐藏字幕或启用柔和动效。浏览器报告页面隐藏时会自动暂停；若浏览器不报告隐藏事件，请用空格暂停。

## 来源与创作

全部台词均为原创文学独白，非秦始皇原话。结尾不是历史人物的真实悔悟记录。见[`facts.md`](facts.md)中的逐条来源与边界，片内亦有说明。未使用游戏画面、影视原声、既有歌曲旋律或声音克隆。

## 结构

- `story.mjs`：180秒时间轴、声音窗口和具体分镜；不是自动循环模板。
- `art.js`、`world.js`：768×432硬像素画面，任意时间确定性绘制。
- `player.js`：以当前原生音轨绝对时间为时钟，不依赖帧数累加；两条音轨永不同时播放。
- `index.template.html`、`style.css`：独立封面、固定字幕层、全屏控件与来源说明。
- `score.mjs`、`audio-test.mjs`、`audio/`：新主题D–A–G–C–F、原创DSP、真实语音边界与混音。162秒旋律保持、从Dm重新配F和声；不是简单加速加响。
- `fonts.mjs`、`assets/`：Google Fonts提供的思源宋体中文子集及OFL许可。下载仅在制作时发生。
- `build.mjs`：校验台本、音轨、字幕哈希，内联画面代码和字体，将两条MP3原样复制到交付目录的`audio/`；构建拒绝内嵌音频。
- `test.mjs`：最终HTML断网、截图、字幕、控制、完整实播与移机验证。
- `protect.mjs`、`previous-films.json`：243个既有作品文件的只读SHA-256基线。
- `output/qa/`、`output/audio-qa/`：验收证据，不随片交付。

## 制作与验收命令

从仓库根目录执行：

- `node qin/build.mjs`：仅构建HTML；有效字体缓存可离线重用。
- `node qin/score.mjs`：重合成音轨，逐句验证后重用有效的语音缓存；新台词需联网合成，**播放不联网**。先按实际修改更新其锁定台本哈希，不能绕过陈旧素材检查。
- `node --test qin/audio-test.mjs`：独立完整解码、响度/峰值、语音可见性、精确音乐留白、频谱转和声及文件哈希验收。
- `node qin/test.mjs --shots`：逐镜截图与画面拼图。
- `node qin/test.mjs --delivery`：短时验证外置音轨、复制目录离线播放、切轨、暂停、全屏、结尾与重播，不重跑全片；加`--edge`检查Edge。
- `node qin/test.mjs --full --headed`：Chrome可见窗口的完整180秒正常速度实播、控制和观看目录移机检查。
- `node qin/test.mjs --edge`：Edge断网兼容和控制检查，不等于另一次全片实播。
- `node qin/protect.mjs`：复核旧片未变，不重建旧片。

共用仓库现有`web/node_modules`里的Playwright和ffprobe；FFmpeg与edge-tts沿用已安装环境。无需API密钥或新增`.env`。

音频制作的客观测量不等于人耳试听；浏览器测试通过也不等于审美通过。硬件性能按用户已有要求跳过，不以本机帧率决定降画质，不宣称已实测用户目标设备。所有验收结论以对应JSON中的最终HTML哈希、执行模式及实测结果为准。
