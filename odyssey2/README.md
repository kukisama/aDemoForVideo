# 奥德赛 II · 空弦

**独立的30秒HD-2D动作演示。** 不修改 `odyssey/`、`export/奥德赛/` 或其他旧片。

## 观看

打开 [`../export/奥德赛2/开始观看.html`](../export/奥德赛2/开始观看.html)，用完整 Chrome / Edge，点击开始或全屏。**这个 HTML 已内嵌全部默认播放资源，可单独复制离线运行。** 交付目录中的三条 MP3 额外保留供独立试听。

需要 WebGL2 和 HDR 渲染目标支持。默认1280×720完整后期；均衡档960×540由观看者手动选择，不根据本机性能自动降级。空格暂停、左右键逐秒跳转、`R` 重播、`F` 全屏、`M` 静音。

## 验收范围与配乐待办

1. **电影主题变奏未制作。** 用户希望听见原片的熟悉旋律，当前未收到可用于改编的音频。`demo.mp3` 和 `master.mp3` 是原创演示底轨，不是电影主题。封面与设置页明确标注。用户本地音频接入可保留旋律并叠加同步音效；“空间回声”只是混音，不等于主题编曲已经完成。
2. **硬件性能按用户要求跳过，不阻碍交付。** 2026-10-06 用户明确：当前电脑配置不代表目标机器，目标测试/播放机器性能足够，不需继续关心本机硬件能力。因此以此为前提保留完整电影档，不再围绕本机帧率优化、降画质或反复测试。验收关注功能、正确时序、画面内容和旧工程完整性；帧数、墙钟与帧间隔仅作为设备观测，不设置通过门槛。“跳过硬件项”不改写为“已在实体GPU测得流畅”。

## 本次做出的变化

- **真实3D环境＋2D像素角色**：14根雕饰柱、透视石砖、镶嵌金属地纹、前景植物与碎石、深处门廊和天井；不是旧版像素画布平移。
- **21种关键帧姿势**：118px高的青铜旅人与135px高的重卫拥有不同轮廓、武器与动作骨架；预备、接触、收招、深蹲、滑行、腾空、回弹、披风惯性。
- **格挡有接触依据**：两处接触由实际像素盾手和矛尖检测，距离分别0.2213与0.1883世界单位，在盾面范围内。缴械时删除手持矛像素，掉落的3D矛继续运动。
- **现代动作反馈**：短暂停顿、2/4/6帧残像、从真实武器尖端历史位置计算的曲线光轨、火花、碎屑、落地尘圈、局部照明与空间声波。
- **HDR与真实深度景深**：透视深度纹理驱动焦点，12次颜色/深度采样、Bloom、SMAA、ACES；不是只给背景叠一张模糊滤镜。光束为透明几何片，人物阴影为月光方向地面投影，不冒充体积光追或全场景光线追踪。
- **声音与动作共用时钟**：默认音轨30秒；14个动作音效逐采样检查。外部本地配乐与音效用同一48kHz AudioContext、相同开始时间调度，避免双HTMLAudio起播漂移。

全片只演示试弦、交锋、闪避、腾空、回身与弦声释放。不宣称这些招式、光波或造型是电影原镜头；没有导入电影或《八方旅人》等游戏资产。

## 开发与验收

使用现有 `web/node_modules/` 的 Three.js 0.186.1、Vite 8.3.2、Playwright，不修改原依赖文件。无API密钥、环境变量或云服务。

- `node odyssey2/build.mjs`：生成 `ODYSSEY2.html` 与 `export/奥德赛2/开始观看.html`，内嵌模块、默认音乐/音效及字体。
- `node odyssey2/sprites-test.mjs`：21种姿势、镜像、过渡、接触、像素范围与缴械检查。
- `node odyssey2/audio-test.mjs`：8项声音测试，包括三轨完整解码、实际响度/真峰值和起音对齐。
- `node odyssey2/test.mjs`：Chrome最终离线文件功能检查，本次53项通过；**不等于完整实时流畅性测试**。
- `node odyssey2/test.mjs --edge`：Edge同类功能检查，本次53项通过。
- `node odyssey2/test.mjs --capture`：关键动作实图。
- `node odyssey2/test.mjs --full`：可见全屏30秒功能实播，检查结束与重播；按用户要求不将本机帧数、墙钟耗时和帧间隔作为硬件通过门槛，报告显式记录 `hardwarePerformance.status=SKIPPED_BY_USER`。
- `node odyssey2/render-test.mjs`：独立GPU像素、确定性、对象寿命与上下文丢失测试；默认640×360，不能据此声称1280×720流畅。
- `node odyssey2/verify-old.mjs`：核对79个旧片源码与交付文件哈希。已有基线不可覆盖。

`timeline.mjs` 是动作/音效契约，`sprites.mjs` 负责像素姿势，`scene.mjs` 负责3D、后期与特效，`player.mjs` 负责媒体控制和本地混音。`output/qa/` 只放QA，不进入观看HTML。
