# 西部余烬 · 三分钟 8-bit 西部史诗

**入口：[export/西部余烬/开始观看.html](../export/西部余烬/开始观看.html)**。整个目录复制即可，保留 `audio/master.mp3`；无需联网、服务器、Node.js 或安装依赖。不生成 ZIP 或视频文件。

180 秒 / 128 BPM / 384 拍 / 13 幕 / 37 段字幕 / 原创 8-bit 音乐，无旁白。

## 故事与边界

围绕“有人许诺明天，有人必须扛着今天往前”，介绍《荒野大镖客 2》的亚瑟·摩根、帮派与时代处境。只使用[官方开篇设定](https://www.playstation.com/en-us/games/red-dead-redemption-2/)，不讲述主要结局。详见 [facts.md](facts.md)。

达奇和亚瑟的戏剧对白是原创改写，**不是游戏原台词**；所有镜头是原创像素蒙太奇，不是游戏实录、精确地图或某个任务的逐镜复现。没有使用、采样或改编游戏原声，不与官方关联或声称背书。

## 画面与音乐设计

- 640×360 二维像素画布：13 个长短不同的段落，不使用 3D 翻转。
- 人物：亚瑟、达奇、营地成员、旅行者的独立色板；步行、指向、提灯、书写、坐姿和伸手。
- 马匹：四腿分段动画、鬃尾、缰绳、鞍具；步行、疾驰、停驻与腾跃位移。
- 场景：多层雪山马队、营地群像、河谷、工业街道、电车、林间奔行、风暴桥梁、列车与黎明。
- 音乐：原创旋律动机经过暖色大调、机械节奏、留白、高潮、冷色对答和开放式终止；不循环拼接上一部音乐。
- 103.125–103.59375 秒一拍留白；108.75 秒最大释放；178.8–180 秒淡出。

## 文件

- `story.mjs`：台本、时间轴、事实引用与13幕结构。
- `art-characters.js`、`world.js`：原创像素角色和电影场景。
- `player.js`、`index.template.html`、`style.css`：本地音乐绝对时钟驱动播放器与字幕。
- `score.mjs`、`audio/`：原创配乐生成、母带和核验报告。
- `build.mjs`：生成项目内 `WESTERN.html` 和独立交付目录，核对故事与音轨哈希。
- `test.mjs`：直接打开交付文件、离线播放与角色/字幕/全屏验收。
- `output/qa/`：实测截图与报告，不进入交付目录。

## 开发验证

在仓库根目录：`node rdr2/build.mjs`；`node rdr2/test.mjs --full` 完整实播；`node rdr2/test.mjs --edge` 做 Edge 兼容检查；`node rdr2/score.mjs --verify` 复验音频。

浏览器验证默认不占用桌面，但仍按正常速度完整运行 180 秒；附加 `--headed` 可显示测试窗口。全屏启程按钮、声音时钟、逐幕字幕、暂停与重播均通过浏览器交互检查，不用加速时钟代替完整实播。

开发阶段共用 `web/node_modules/` 的字体、Playwright、ffprobe；观看交付文件不需要这些依赖。此前作品保持不变。
